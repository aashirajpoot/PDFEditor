# 📄 PDF Editor (Streamlit)

A modern and user-friendly **PDF Editor Web Application** built with **Python** and **Streamlit**. This tool allows users to perform common PDF operations directly from their browser without installing any heavy desktop software.

## 🌐 Live Demo

🔗 https://pdf-editor-aashi.streamlit.app

---

## 🚀 Features

### 📑 Merge PDFs

Combine multiple PDF files into a single document.

### ✂️ Split PDFs

Extract individual pages or split a PDF into separate files.

### 📝 Extract Text

Retrieve text content from PDF documents quickly and efficiently.

### 🖼️ Extract Images

Extract and download images embedded inside PDF files.

### 🔐 Encrypt PDFs

Protect PDF documents with a password for enhanced security.

## ▶️ Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/aashirajpoot/PDFEditor.git
cd PDFEditor
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Start the Application

```bash
streamlit run pdf_editor.py
```

## 📌 Project Goal

The goal of this project is to provide a simple, accessible, and lightweight solution for performing everyday PDF operations through an intuitive web interface. Users can edit and manage PDF files without requiring expensive or resource-heavy software.
