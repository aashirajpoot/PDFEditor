📄 PDF Editor (Streamlit)

A simple and interactive **PDF Editor web app** built using Python and Streamlit.

🚀 Features
- 📑 Merge multiple PDF files
- ✂️ Split PDF into pages
- 🔐 Encrypt PDF with password
- 🖼️ Extract images from PDF
- 📝 Extract text from PDF

🛠️ Tech Stack
- Python
- Streamlit
- PyPDF2

▶️ How to Run Locally

1. Clone the repository:
git clone https://github.com/aashirajpoot/PDFEditor.git cd PDFEditor

2. Install dependencies:
pip install -r requirements.txt

3. Run the app:
streamlit run pdf_editor.py

## 📌 Project Goal
This project aims to provide a **simple and user-friendly interface** for performing common PDF operations without needing heavy software.
